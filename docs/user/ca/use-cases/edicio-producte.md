# Cal editar un producte

**Situació:** Cal corregir les dades d'un producte que ja existeix al catàleg.

## Editar i desar

1. Obre **Productes** des del menú d'administració o d'estoc.
2. Cerca el producte amb els filtres de codi de barres, referència, nom, categoria o marca.
3. Selecciona el producte i modifica les dades necessàries. Pots editar, entre d'altres, el nom, la referència, la categoria, els preus, l'estoc i les propietats.
4. Revisa els canvis i prem **Desa**.
5. Si canvies de producte o filtres mentre hi ha canvis sense desar, escull **Desa**, **Descarta** o **Cancel·la** quan aparegui l'avís.

## Descartar canvis

Si encara no vols desar l'edició, prem **Descarta**. El formulari torna a les dades desades del producte actual.

## Eliminar

No eliminis un producte per corregir-ne les dades. Per eliminar-lo, prem **Elimina** i confirma l'acció; l'eliminació és permanent.
