# La venedora necessita obrir el calaix sense fer una venda

**Situació:** La venedora necessita accedir a l'efectiu però no està venent cap producte.

## Obrir el calaix

1. Busca **Obre el calaix** a la fila d'accions de venda, damunt del tiquet.
2. Prem l'acció.
3. Si el caixer demana autorització, demana a una supervisora que autoritzi l'operació.

No creïs un tiquet buit només per obrir el calaix.
