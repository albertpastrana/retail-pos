# La clienta vol pagar a trossos

**Situació:** La clienta vol utilitzar més d'un mètode de pagament, per exemple un val i una targeta, o efectiu i targeta.

## Afegir el primer pagament

1. Prem **Igual** després de revisar el tiquet final.
2. Selecciona la primera pestanya de pagament.
3. Introdueix l'import que vols aplicar.
4. Prem l'acció de pagament parcial o d'afegir pagament. Encara no premis **D'acord**.
5. Comprova l'import pendent que mostra la finestra de pagament.

## Afegir el pagament restant

1. Selecciona la segona pestanya de pagament.
2. Introdueix l'import que queda.
3. Afegeix el pagament.
4. Continua fins que l'import pendent sigui zero.
5. Prem **D'acord** per confirmar el pagament mixt complet.

El tiquet s'imprimeix després de confirmar tot el pagament. El mateix circuit serveix quan un val regal només cobreix una part del tiquet: afegeix primer el val i paga la resta amb un altre mètode.
