# La clienta vol comprar un val regal

**Situació:** La clienta vol marxar amb un val que una altra persona podrà utilitzar més endavant.

## Vendre el val

1. Comença un tiquet nou si la clienta no compra res més.
2. Cerca i afegeix el producte val regal.
3. Comprova l'import i la quantitat. Els vals regal es venen en unitats senceres.
4. Prem **Igual** i completa el pagament amb normalitat.
5. Lliura a la clienta el val emès o el seu tiquet.

No tractis la venda del val com un bescanvi de fidelització. La venda d'un val no genera segells.
