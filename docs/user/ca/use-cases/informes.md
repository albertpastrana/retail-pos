# Informes de gestió

**Situació:** Cal consultar vendes o estoc sense bloquejar el caixer.

## Informes disponibles

Al menú d'informes hi ha actualment:

- **Resum de vendes:** tiquets, brut, devolucions, net, impostos i mitjana per tiquet.
- **Vendes per producte:** referència, producte, categoria, unitats i import.
- **Vendes per mètode de pagament:** vendes, devolucions i net per mètode.
- **Estoc baix:** estoc actual, mínim, màxim i unitats a demanar.

## Consultar un període

1. Obre l'informe corresponent.
2. Selecciona la data inicial i final.
3. Prem **Carrega**.
4. Revisa els resultats i ordena les taules quan calgui.

Els informes poden trigar una mica perquè consulten la base de dades. No tanquis l'aplicació mentre estan carregant.

Els informes agrupats per model, el tancament de caixa com a informe i l'exportació CSV formen part del treball de reconstrucció i encara no s'han de donar per disponibles.
