# Cal corregir o retornar una venda acabada

**Situació:** Un tiquet acabat té un error o la clienta necessita una devolució.

## Editar un tiquet

1. Obre la llista de tiquets acabats.
2. Selecciona el tiquet original.
3. Prem **Edita**.
4. Revisa totes les línies afectades i l'import resultant.
5. Confirma l'edició quan el tiquet sigui correcte.

Per editar cal autorització d'una supervisora. Si l'acció no està disponible, demana ajuda; no repeteixis la venda antiga com una venda nova.

## Fer una devolució

1. Selecciona el tiquet original a la llista de tiquets acabats.
2. Prem **Retorna**.
3. Selecciona les línies que es retornen i comprova'n les quantitats.
4. Revisa l'import de la devolució i confirma'l.

Per fer una devolució cal autorització d'una supervisora. La devolució utilitza el tiquet original com a referència en lloc de crear una venda nova sense relació.
