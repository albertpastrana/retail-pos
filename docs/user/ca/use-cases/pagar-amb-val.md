# La clienta vol pagar amb un val regal

**Situació:** La clienta ja té un val regal i vol utilitzar el saldo que li queda.

## Utilitzar el val

1. Prem **Igual** al teclat de vendes després de revisar el tiquet.
2. A la finestra de pagament, selecciona la pestanya de pagament amb val.
3. Introdueix o escaneja el codi del val.
4. Comprova el saldo disponible que mostra el caixer.
5. Si el val cobreix tot l'import, prem **Utilitza el val** i després **D'acord**.

## Quan el val és parcial

Si el val no cobreix tot el tiquet, el caixer mostra l'import que queda:

1. Prem l'acció de pagament parcial per afegir l'import del val.
2. Selecciona la pestanya d'efectiu, targeta o un altre mètode.
3. Introdueix i afegeix l'import restant.
4. Prem **D'acord** només quan l'import pendent sigui zero.

Si el val no es troba, està buit o no es pot comprovar, no n'improvisis el valor. Atura el pagament i demana ajuda a la persona responsable del caixer.

**Recorda:** Utilitzar un val com a pagament és diferent d'afegir la línia de fidelització de `-5 EUR`.
