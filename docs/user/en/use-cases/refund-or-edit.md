# A completed sale must be corrected or returned

**Situation:** A completed receipt contains a mistake or the customer needs a refund.

## Edit a receipt

1. Open **Edit sales**.
2. Select a recent sale or search for the receipt number.
3. Press **Edit**.
4. Check every affected line and the resulting amount.
5. Correct the receipt and press **Equals**.
6. Review the payment window and confirm the operation.

Editing requires supervisor authorisation. If the action is not available, ask a supervisor; do not recreate the old sale as a new one.

## Refund a receipt

1. In **Edit sales**, select the original receipt.
2. Press **Refund**.
3. On the refund screen, select a line and press **One unit**, **Line**, or **All** as appropriate. Check the quantities.
4. Press **Equals**, check the amount, and choose the refund method in the payment window.
5. Press **OK** to save the refund.

Refunding requires supervisor authorisation. The refund uses the original receipt as its reference rather than creating an unrelated new sale.
