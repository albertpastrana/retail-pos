# A sale must be continued later

**Situation:** The customer is not ready to finish, or the current receipt must be left open temporarily.

## Park the receipt

1. Press the parked-receipt action in the sales actions row above the receipt, or use the action that starts a new receipt.
2. Check that the current receipt is no longer the active one.
3. Leave the receipt parked until the customer is ready.

## Resume the receipt

1. Open the parked-receipt list.
2. Select the receipt using the seller, date, time, and product lines shown.
3. Check the seller, products, quantities, and total before continuing.

Changing seller or leaving the sales screen may also save or park the current receipt. Do not create a second receipt when the customer's original receipt is already parked.
