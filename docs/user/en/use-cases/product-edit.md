# A product must be edited

**Situation:** Staff need to correct a product that already exists in the catalogue.

## Edit and save

1. Open **Products** from the administration or stock menu.
2. Find the product with the barcode, reference, name, category, or brand filters.
3. Select the product and change the required fields. You can edit the name, reference, category, prices, stock, and properties, among other fields.
4. Review the changes and press **Save**.
5. If you change product or filters while there are unsaved changes, choose **Save**, **Discard**, or **Cancel** when prompted.

## Discard changes

If you do not want to save the edit, press **Discard**. The form returns to the saved values for the current product.

## Delete

Do not delete a product to correct its data. To delete it, press **Delete** and confirm; deletion is permanent.
