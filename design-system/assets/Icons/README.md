The icon family uses Lucide as its reference: 24×24 viewBox, 2px stroke, rounded caps and joins, and `currentColor` so Swing can use the active light or dark theme. The replaceable icons are local copies of Lucide's `printer`, `credit-card`, `tag`, and `search` SVGs. `barcode-scan` and `cash-drawer` are POS-specific exceptions because their meanings are not provided by an exact Lucide glyph; they use the same outline geometry and stroke rules. The sidebar uses Lucide `panel-left-open` and `panel-left-close`.
