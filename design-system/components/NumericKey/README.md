The keypad key: quantity entry, price override, cash tendered. Always laid out in a fixed grid (a standard 3×4 phone-style pad plus a wide `0` and a `⌫`/clear key), never reflowed — a cashier's muscle memory depends on `7` always being top-left. Digits are set in `price` (IBM Plex Mono), not `body-lg`, so the key matches the monospaced total it's building up on the ticket above it.

Every key is `space-12` (48px) square at minimum, sitting in `surface-200` — the pad reads as one sunken well against the sales screen's `surface-0`, with each key raised one step off that well (`surface-100`, `shadow-raised`) so the grid itself is visible even before anything is pressed. The active/pressed state is `brand` fill with `on-brand` text, exactly like a primary button, since a key mid-press *is* a primary action. Never colour a digit key `danger`; the clear key uses `ink-muted`, not red — clearing an entry isn't a destructive action, closing the till or voiding a completed line is.
