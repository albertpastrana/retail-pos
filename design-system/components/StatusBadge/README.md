A small, filled, all-caps label for a state that matters at a glance: a ticket's `Paid`/`Held`/`Void`, a stock row's `Low stock`, a report row's `Pending`. Text is `label` (12px, 700 weight, tracked) inside a `radius-full` pill.

The four states map onto the four semantic colours one-to-one and never mix — `success` (`Paid`, `In stock`), `warning` (`Held`, `Low stock`), `danger` (`Void`, `Out of stock`), `info` (`Pending`, `Imported`). Every badge's fill is the semantic colour at low opacity against `surface-100`/`surface-0`, with the semantic colour itself as the text — not a solid semantic fill with white text, which reads closer to a button and competes with the one `primary` action on the screen. A badge is never interactive; if a state needs to be clicked or changed, that's a `Button`, not a `StatusBadge` with an `onClick`.
