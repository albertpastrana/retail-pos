# Replenishment row status colors

Captured: 2026-10-22

Related: `tickets/done/replenishment-form-layout.md`

## Goal

Replenishment table colors communicate the operational status consistently.

## Done when

- Every unselected row uses one background color based on its status.
- The type column does not apply a competing row-wide color.
- The status cell retains its stronger status text color.

## Shipped

Rows now use the pending, ordered, or received status color consistently across
all columns.
