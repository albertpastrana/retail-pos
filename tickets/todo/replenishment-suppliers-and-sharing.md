## UX layout decisions

- At widths of at least 1200px show suppliers in a ~232px left sidebar aligned with the status tabs: All suppliers, Unassigned, separator, then suppliers. Each is one 48px borderless row with its active-status count in muted mono inside, right aligned. The active row has a rounded `surface100()` background and 2px `borderStrong()` outline; keyboard focus follows the same 10px arc. An empty supplier list shows a caption ("No suppliers yet"). A ghost Manage suppliers button with edit icon follows the items, not the bottom of the screen. Below 1200px use the supplier combo instead and keep nine typical rows at 980px; do not show both controls at once.
- Status is one compact content-width `surface200()` segmented container with 4px padding and borderless, 44px Manrope-semibold buttons in this order: Pending, Ordered, Received, Delivered, All. Pending is the default. The active segment has a rounded `surface100()` background, raised shadow and bold text without an inner rectangular outline. Brand is reserved for the current primary action.
- Show the Supplier table column only in All suppliers; unassigned entries have muted ink text, not warning colour. Product cells show a small mono reference above the name; unmatched entries use the translated Manual label.
- In a named supplier view group rows with non-selectable Brand · Family headings, placing entries with neither under Unbranded / no family last. Other views stay newest first.
- The right-hand CardLayout has four states: no selection in a named supplier view shows an Order panel with the outgoing count, short preview, WhatsApp primary (disabled with a reason if no phone), Text file and Print; no selection elsewhere shows the **New request** form; one selection shows details with status badge, a single next-step primary action, supplier/customer Change controls, note, separated confirmed Delete, and Undo/Save only for editable details; multiple selections show a Selection panel with one-touch supplier buttons (pending entries only), New supplier, Mark ordered and confirmed Delete. The creation form's Cancel is enabled only once data is entered.
- Remove the upper Manage/Assign buttons and bottom Mark as row. The footer shows **N of M selected** in bold 17px Manrope, Select all and Deselect as ghost controls (Deselect disabled or hidden with zero selected), and a right-aligned Export when none are selected / Export selection (N) when some are selected, outside a named supplier view.
