# Process sales returns

Captured: 2026-09-19

## Goal

Allow an operator to process a return for a previous sale from the till.

## Context

A return could not be completed. Investigate the blocked or missing return flow and make the operator action usable, including the resulting refund and stock changes.

## Done when

- An operator can start a return from the expected sales or ticket screen.
- Returned items, refund payment, and stock quantities are recorded correctly.
- Invalid quantities and already returned items are rejected with a clear message.
